# 著作権クリア照会メモ（ドラフト）

並行トラック用。法律アドバイスではない。アプリ実装は AI 予想問題本線を継続する。

## 権利者候補

- 一般財団法人 不動産適正取引推進機構（RETIO）
  - 過去問題公開: https://www.retio.or.jp/exam/past_ques_ans/other/
- （必要に応じて）市販過去問題集の出版社

## 照会文に含める項目

1. 利用主体・アプリ名（宅建合格ロード）・有料/無料の別
2. 掲載したい範囲（例: 直近10年・問題全文 / 肢のみ / 正解番号のみ）
3. 改変（法改正対応の改題）の可否
4. クレジット・リンク義務の希望確認
5. 想定ユーザー規模と対価の相談意向
6. 回答希望期限

## 許諾前の方針

- アプリ内に過去問本文は載せない
- 公式 PDF へのリンク導線は可
- 他サイトからのスクレイピング転載はしない

## 許諾後

- `past-exam` レイヤを AI プールと分離して実装
- 画面に出典・利用条件を表示
- `_backup_copyrighted` の無審査リストアは禁止
